# Code of Conduct

## The short version

Be decent. Assume the other person is acting in good faith. Argue about code,
not about people.

## What is expected

- Keep criticism about the work: what it does, what it breaks, what it claims.
- Accept that a maintainer may say no, and say why.
- Report a security issue privately first. See [SECURITY.md](SECURITY.md).

## What is not

Harassment, personal attacks, or discriminatory language of any kind. Deliberately
wasting a maintainer's time. Publishing someone's private information.

## Enforcement

Report a problem by opening an issue, or privately through the contact in
[SECURITY.md](SECURITY.md) if it should not be public. The maintainer will read
every report and respond. Behaviour that continues after a warning ends
participation in this repository.

This is a small project. This document exists so that expectations are written
down rather than assumed, not because a process is needed.
