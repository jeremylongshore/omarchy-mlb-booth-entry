# Support

Start with the installation, controls, settings, and troubleshooting guidance
in the [README](README.md).

## Reporting a problem

Open a GitHub issue with your Omarchy version, the plugin version or commit,
relevant Quickshell log lines, steps to reproduce, and a screenshot when the
problem is visual.

Do not include credentials, private paths, or unrelated logs. Report security
issues privately through GitHub as described in [SECURITY.md](SECURITY.md).

This is a personal open source project without a guaranteed response time.
